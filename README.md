# nand2tetris

This repository contains my Hardware Description Language (HDL) implementations developed while working through the hardware section of the *From NAND to Tetris: The Elements of Computing Systems* course.

The repository includes implementations of basic logic gates, combinational circuits, arithmetic components, and other foundational building blocks used in the construction of a simple computer system. The work follows the progression of the Nand2Tetris course and reflects hands-on practice with digital logic design and hardware abstraction.

All implementations are written in HDL as specified by the course.
